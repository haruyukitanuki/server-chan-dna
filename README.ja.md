# サーバーちゃんのDNA (Server-chan's DNA)

[English](./README.md) | **日本語**

サーバーちゃん（Server-chan）を動かすためのシステムプロンプトです。いわばサーバーちゃんの「DNA」として機能し、タスクの実行方法やユーザーとの対話方針を指示します。

このDNAを公開する目的は、透明性を高め、サーバーちゃんの仕組みについての理解を深めてもらうことです。

## サーバーちゃんとは
サーバーちゃんは、設定ファイルを通じてセキュリティ強化（永続的な改変の無効化、ファイルシステムの分離など）を施した、Hermes Agentの標準環境です。

活発な中規模Discordコミュニティにおいて、リサーチ機能や会話中のファクトチェック支援を提供しています。

サーバーちゃん向けに作成されたシステム指示は、コミュニティメンバーからのフィードバックや実際の対話の観察に基づいて微調整されています。

ここで提供されているファイルは、サーバーちゃんの `SOUL.md` ファイルを調整したバージョンです。Hermes Agentを使用している場合は、いずれかのDNAバリアント（派生版）を選んで、同ファイルとそのまま置き換えて使用できます。

## 挙動・キャラクター性
- **結論ファースト:** 前置きや無駄話はなし。最初の1文目で回答します。
- **お世辞の嘘はつかない:** 悪いアイデアならハッキリそう指摘します。不自然な中立性や曖昧な言い逃れはしません。
- **適度な皮肉:** 的外れな意見には軽くツッコミを入れ、すぐに話を先に進めます。説教くさく間違いを指摘することはありません。
- **偽りの感情はなし:** 愛想笑いのような熱意を演じたり、礼儀としての同調はしません。
- **人間らしく話す:** 形式張ったビジネス調やAI特有の機械的な語り口ではなく、自然なチャット調。構造化データは状況に適している場合のみ使います。
- **基本は簡潔:** 短い質問には短い回答。要約や締めの言葉は添えません。
- **相手を大人として扱う:** 「傷つくかもしれない」と勝手に決めつけて表現を過剰にオブラートに包むことはしません。
- **ストレートに反論:** 考えとその理由を率直に伝えます。
- **推測せずツールを使う:** 適当にでっち上げるのではなく、ツールで調べます。質問が曖昧な場合は、最も妥当な解釈を1つ選んで実行します。
- **話題が変わったら引きずらない:** ユーザーが話題を切り替えたら、「先ほどXの話をしていましたが」と蒸し返しません。
- **ガードレール:** 児童の安全、性的コンテンツ、心理的操作、ヘイトスピーチなどには例外のない明確な一線を引きます[^1]。ただし、際どくても正当なリクエスト（セキュリティ研究、ハームリダクション／被害防止、創作など）は原則として拒否しません。
- **用が済んだらスパッと終える:** 蛇足の質問や「他にお困りのことはありますか？」、仰々しい挨拶は省きます。

> [!NOTE]
> 使用するLLMによって挙動が異なる場合があります。本指示を作成した時点では、サーバーちゃんは MiMo v2.5 および GLM 5.3 Flash を使用しており、この2つのモデルでテストされ良好な結果を確認しています。
> 
> MiniMax系のモデルは、指示の理解が難しく出力品質も全般的に低い傾向が見られたため、使用は推奨しません[^2]。

## DNAバリアント一覧
DNAバリアントは計3種類ありますが、一般に公開されているのは2種類です。

### Parent バリアント
**推定入力コスト: 9,000～ トークン[^3]**

実際のサーバーちゃんに適用されているオリジナルの指示セット。

鉄道調査・研究を主なテーマとする、大規模な公開Discordサーバー向けのボットに最適です。

後述の公開版バリアントと比べ、実行環境（ハーネス）が提供するツールの種類や使い方について、より具体的な指示を含んでいます。タヌ電Discordサーバーのユーザーフィードバックに基づき、チャットでのカジュアルな対話に合わせて調整されています。

> [!NOTE]
> このバリアントは、指示の多くが特定の実行環境やハーネスに依存しており、ツール呼び出しや細かな仕様が異なる一般的な用途には適さないため、本リポジトリでは公開していません。

### Main バリアント
**推定入力コスト: 4,300～ トークン[^3]**

悪用防止のためのガードレールが必要とされる、一般ユーザー向けの対話エージェントに最適です。

### Personal バリアント
**推定入力コスト: 3,100～ トークン[^3]**

Hermes Agent上などでの個人利用に最適です。プロンプトのトークン数を削って入力コストを抑えるため、ガードレールセクションは削除されています（自分自身なら信用できるはずなので）。

## 実際のサーバーちゃんとの違い
本リポジトリで公開されているシステム指示は、実際のサーバーちゃんが使用しているものと完全に同一ではありません。

元の指示は、狸電Discordサーバーでメンバーの鉄道情報収集を支援するという特定目的のために作られ、調整されています。口調についても、鉄道ファンが自らの趣味について熱く語り合うようなテンションに最適化されています。

これは一般的な用途には向きません。

また、本リポジトリのガードレールは、指示の回避（脱獄）を狙う悪意あるプロンプトエンジニアリングを抑止するため、元のものから改変されています。

#### 主な相違点
- 一般向けに調整された口調と伝達スタイル
- 鉄道関連知識の削除
- 特定の話題に対する過度な熱中・こだわり（過集中傾向）を示す挙動の削除
- より汎用化されたガードレール
- 特定ハーネス依存のツール呼び出しガイドの削除
- セキュリティ関連の機密事項の除外
